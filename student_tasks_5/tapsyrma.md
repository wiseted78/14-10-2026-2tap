# Практикалық жұмыс: HTML және CSS қателерін түзету

**Сайт тақырыбы:** «Студенттің тапсырмалар тізімі».
**Деңгейі:** бастапқы. **Ұсынылатын уақыт:** 60–90 минут.

## Мақсат

Сайттағы қарапайым қателерді байқап, HTML және CSS кодын түзету. Сайттың дұрыс ашылуы мен сыртқы көрінісін тексеруді үйрену.

## Не істеу керек?

1. `README.md` бойынша жобаны іске қосыңыз.
2. Өзіңіздің тіркелгіңізді жасап, жүйеге кіріңіз.
3. Тапсырмалар тізімін, жаңа тапсырма бетін және нұсқаулықты қарап шығыңыз. Мәзір мен бет ішіндегі сілтемелерді тексеріңіз.
4. Сайтта әдейі жасалған **дәл 5 қарапайым қате** бар. Барлығы HTML немесе CSS файлдарында орналасқан. Оларды тауып, түзетіңіз.
5. Әр түзетуден кейін файлды сақтап, браузерді жаңартыңыз. CSS өзгерісі көрінбесе, `Ctrl+F5` басыңыз.
6. Терезені тарылтып, сайттың телефон экранына бейімделуін тексеріңіз.

**Python кодын, SQLite базасын, тіркелу мен кіру логикасын өзгертпеңіз.** Бұл бөліктер дұрыс жұмыс істейді. Қателерді бір-екі жолды өзгерту арқылы түзетуге болады.

## Дұрыс нәтиже қандай болуы керек?

- Тіркелу, кіру және шығу жұмыс істейді.
- Кең экранда тапсырмалар бөлек, арасы ашық карточкаларда орналасады; телефонда бір бағанға түседі.
- Карточка мәтіні шетіне жабыспайды.
- Жаңа тапсырма батырманы басқанда сақталып, тізімде көрінеді.
- Тапсырманы аяқтау, қайта жоспарлау және өшіру жұмыс істейді; сандар жаңарады.
- Сілтемелер қажетті бетке апарады, нұсқаулық ұқыпты безендірілген.

## Қысқа кеңес

HTML беттің құрылымын, ал CSS оның сыртқы көрінісін анықтайды. Файл атауларын, атрибуттарды және жазылуын мұқият салыстырыңыз. Бір уақытта бір ғана өзгеріс жасап, нәтижесін тексеріңіз. Браузердегі `F12` құралдарын қолдануға болады.
