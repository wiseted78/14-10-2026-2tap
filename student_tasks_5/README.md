# Студенттің тапсырмалар тізімі

Бұл нұсқаны жеке іске қосуға болады. Интерфейс қазақ тілінде.

## Орнату

Python 3.10 немесе одан жаңа нұсқасы қажет. Терминалды осы `app.py` файлы орналасқан бумада ашыңыз.

**Windows (PowerShell):**

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

**Linux / macOS:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Браузерде **http://127.0.0.1:5000** мекенжайын ашыңыз. Алдымен тіркеліңіз, содан кейін жүйеге кіріңіз. Әр жаңа тіркелгіге үш үлгі тапсырма қосылады.

Серверді тоқтату: терминалда **Ctrl+C**.

## Басқа портта іске қосу

Егер 5000 порты бос болмаса немесе екі нұсқаны қатар ашсаңыз:

```powershell
.\.venv\Scripts\python.exe app.py --port 5001
```

Linux / macOS үшін:

```bash
.venv/bin/python app.py --port 5001
```

Бұл жағдайда мекенжай: **http://127.0.0.1:5001**.

## Деректер

- `site.db` базасы осы нұсқаның `app.py` файлының қасында автоматты түрде жасалады.
- Тіркелгілер мен тапсырмалар SQLite базасында сақталады. Сервер қайта іске қосылғанда олар жоғалмайды.
- Әр пайдаланушы тек өз тапсырмаларын көреді және өзгерте алады.
- Екі нұсқаның базалары бөлек. Бір нұсқада жасалған тіркелгі екіншісіне көшірілмейді.
- Сервер қайта іске қосылса, жүйеге қайта кіру қажет болуы мүмкін.
- Бұл жоба жергілікті оқу жұмысына арналған.

## Файлдар

- `app.py` — сайттың Flask бөлігі және база жұмысы.
- `templates/` — HTML беттері.
- `static/css/` — CSS файлдары.
- `tapsyrma.md` — студентке арналған тапсырма.
- `requirements.txt` — қажетті пакет.
